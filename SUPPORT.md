# Support

MDx is early, and support is currently best effort.

## Hosted Beta

For an invite, use the waitlist at [mdx-os.com/waitlist](https://mdx-os.com/waitlist).
For an account-specific beta problem, reply to the message that delivered your
invite. Do not post email addresses, invite ids, access tokens, or private
workspace details in a public issue.

## Self-Hosted MDx

Start with the [quickstart](docs/QUICKSTART.md). If the problem remains, search
existing issues and open a bug report with:

- the MDx revision or release
- your operating system and tool versions
- the smallest safe reproduction
- expected and observed behavior
- redacted logs or screenshots when they help

Questions and product ideas are welcome through the matching issue form. A
public issue is not a private support channel, and response times are not
guaranteed.

## Security

Do not report vulnerabilities or include exploit details in a public issue.
Follow [SECURITY.md](SECURITY.md) instead.
